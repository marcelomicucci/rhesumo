# Rhesumo — Diário de Bordo do Grupo Rhes

produzido pelo [Grupo Rhes](https://rhes.com.br) em Belém (PA). Cada item traz um resumo próprio e o link
para a matéria original; itens internacionais têm resumo traduzido para o português.

**Site com a edição do dia e busca avançada:** https://marcelomicucci.github.io/rhesumo/

- `edicoes/AAAA/MM/` — edições em Markdown
- `dados/edicoes/` — edições em JSON · `dados/indice.json` — índice usado pela busca

Os direitos das matérias pertencem aos respectivos veículos.
